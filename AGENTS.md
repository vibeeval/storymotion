# Source contributions

Read README.md, QUICKSTART.md and LICENSING.md before changing this project.
Original StoryMotion code is MIT licensed; retained third-party material keeps its own terms.
Preserve loopback binding, session authentication, path and ownership checks, immutable input receipts,
provider endpoint allowlists, per-request spending approval, explicit downloads and runtime checks.
HyperFrames is the default renderer. Remotion is an explicit optional dependency.
Keep credentials, local AccountPacks, user media, voice recordings, work data and generated artifacts out of Git.
Use synthetic fixtures and offline tests. Never silently run a paid provider, install dependencies,
change operating-system security, publish, or push. Do not claim native or clean-device acceptance from source tests.
