# Production guidance / Üretim rehberi

TR: Bu paket genel bir içerik üretim yöntemi sağlamaz. Nötr örneği kendi konu, metin, kaynak ve görsel tercihlerinizle uyarlayın. Kaynak doğruluğu, medya hakları ve son çıktının uygunluğu insan incelemesi gerektirir. Başlangıç adımları: [video hazırlama](../docs/PLAN.md).

EN: This package does not supply a complete content-production method. Adapt the neutral example to your own topic, script, sources and visual choices. Source accuracy, media rights and final output suitability require human review. Start with [video preparation](../docs/PLAN.md).
