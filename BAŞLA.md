# Başla / Start

StoryMotion’un Mac ve Windows sürümleri aynı kaynak ağacını kullanır. İlk adım için [Hızlı başlangıç](QUICKSTART.md), kapsam ve MIT lisansı için [README](README.md) dosyasını okuyun.

- Yalnız paneli incelemek: QUICKSTART içindeki **Paneli kaynak koddan açın** adımı; sağlayıcılar kapalıdır.
- MP4 render almak: önce platform önkoşulları ve runtime preflight, sonra açık indirme izniyle kurulum. Windows ayrıntıları: [Windows rehberi](docs/WINDOWS.md).
- Kendi içerik yönteminizi kurmak: [Yapılandırma](CONFIGURATION.md) içindeki nötr AccountPack ve BYOK bölümleri.

Kaynak hazırlama ile bitmiş video farklı aşamalardır. Native Windows ve temiz cihaz kurulumu doğrulanmış olarak sunulmaz. Kamuya açma 2 Kasım 2026 için planlanmıştır; bu kaynak adayı henüz yayımlanmış sürüm iddiası taşımaz.

Mac and Windows share one codebase. Begin with [Quick start](QUICKSTART.md); browse locally with providers off, then install a render runtime separately if needed. Define your own production method in an AccountPack. See [README](README.md) for MIT scope and current validation limits.
