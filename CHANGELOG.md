# Changelog

## 0.14.1 — open-source release candidate

- One shared source tree with macOS shell and Windows PowerShell/Python entry points.
- Original StoryMotion code and original project documentation use the MIT License. Third-party terms remain separate.
- Neutral AccountPack, 91 parameterized templates and 182 input examples retained.
- Providers start off; local session, input integrity, spending approval and runtime checks remain enforced.
- `--license-sha256` is the primary reviewed-LICENSE hash option. The earlier flag remains a compatibility alias.
- This candidate has not been published. Windows native execution, clean-device installation and all-template visual acceptance remain unverified.
